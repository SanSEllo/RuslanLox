# VirtualLab — Заряд конденсатора в RC-цепи

Учебный проект для лабораторной работы по переходному процессу RC-цепи.

## Исходные данные

Вариант 16:

- Um = 220 В
- R = 50 кОм
- C = 10^-7 Ф
- Uc(0) = 0 В

## Математическая модель

Аналитическое решение:

Uc(t) = Um * (1 - exp(-t / RC))

Дифференциальное уравнение:

dUc/dt = (Um - Uc) / (RC)

Численное решение выполняется методом Рунге–Кутты 4-го порядка (RK4).

Постоянная времени:

tau = RC = 0.005 с = 5 мс

Время достижения 95%:

t95 = -RC * ln(0.05) ≈ 2.996 * RC ≈ 15 мс

## Архитектура

Проект разделён на три части:

- `core/` — физическая модель и solver;
- `export/` — CSV/JSON;
- `ui/` — графический интерфейс.

Core не импортирует UI. UI не содержит реализации RK4 или физической производной.

## Установка

Создать окружение:

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Тесты

```bash
pytest -q
```

## Проверка

В интерфейсе нажмите «Рассчитать».

На графике отображаются:

- аналитическое решение;
- RK4;
- вертикальная отметка t95;
- горизонтальная отметка Um.

Также выводится максимальная абсолютная разница между RK4 и аналитическим решением.

## Экспорт

После расчёта доступны:

- CSV — таблица времени, аналитического решения и RK4;
- JSON — параметры эксперимента и результаты.

- CSV;
- JSON.

## Важное архитектурное правило

Не переносить физику в обработчики кнопок UI.

UI вызывает Core:

```text
UI -> RCParameters -> RCCircuit -> RK4Solver -> SimulationResult -> UI
```

Формулы и шаг RK4 находятся только в `core/`.


## Значения при запуске

Поля при запуске соответствуют варианту 16:
- `Um = 220 В`
- `R = 50000 Ом` (50 кОм)
- `C = 1e-7 Ф`
- `Uc(0) = 0 В`

Все параметры задаются в базовых единицах СИ.
